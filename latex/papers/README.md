# Corpus documentaire

Ce dossier archive les documents effectivement mobilises pour le rapport d etude `L approche agentique dans un contexte de trading multifactoriel`. Le fichier `manifest.csv` constitue l inventaire de controle.

## Articles et documents scientifiques archives

- `fama_french_1993.pdf` - Fama et French (1993), `Common risk factors in the returns on stocks and bonds`. Copie PDF ouverte de l article publiee par Hillsdale Investment Management, avec le titre et les pages de l article original.
- `carhart_1997.pdf` - Carhart (1997), `On Persistence in Mutual Fund Performance`. Copie academique du texte publie dans *The Journal of Finance* ; DOI conserve dans la bibliographie.
- `lewis_2020_rag.pdf` - Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks, arXiv:2005.11401.
- `yao_2023_react.pdf` - ReAct: Synergizing Reasoning and Acting in Language Models, arXiv:2210.03629.
- `schick_2023_toolformer.pdf` - Toolformer: Language Models Can Teach Themselves to Use Tools, arXiv:2302.04761.
- `shinn_2023_reflexion.pdf` - Reflexion: Language Agents with Verbal Reinforcement Learning, arXiv:2303.11366.
- `wu_2023_autogen.pdf` - AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation, arXiv:2308.08155.
- `yang_2023_fingpt.pdf` - FinGPT: Open-Source Financial Large Language Models, arXiv:2306.06031.
- `yu_2023_finmem.pdf` - FinMem: A Performance-Enhanced LLM Trading Agent with Layered Memory and Character Design, arXiv:2311.13743.
- `yang_2026_finrlx.pdf` - FinRL-X: An AI-Native Modular Infrastructure for Quantitative Trading, arXiv:2603.21330.

## Regle de provenance

Tous les articles et documents mobilises dans le rapport disposent desormais d une copie locale dans ce dossier. Lorsqu une version editeur ouverte n etait pas disponible, une version legale de travail, une copie deposee par les auteurs ou une version officielle a ete retenue. Aucune version non autorisee n est incluse.

Les depots GitHub cites sont des sources techniques et non des articles academiques : leurs URLs restent dans `biblio.bib` et leur statut est documente dans les annexes. Ils ne sont donc pas convertis artificiellement en PDF.
